# Support

Semantic Cache is an educational open-source project without private or guaranteed support.

- For a reproducible defect, use the repository's **Bug report** issue form.
- For a proposed capability or improvement, use the **Feature request** form.
- For setup questions, first check [README.md](README.md) and existing issues. If the documented
  workflow appears broken, file a bug with the relevant environment and commands.
- For suspected vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not post credentials, personal data, customer content, or unredacted production logs. A public
issue is searchable and should be treated as permanently public.
