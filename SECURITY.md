# Security Policy

## Supported versions

Semantic Cache has not published a release. Security fixes currently target only the latest
commit on the default branch; older commits and forks are not supported.

## Report a vulnerability privately

Do not open a public issue, pull request, or discussion for a suspected vulnerability.

1. Open this repository's **Security** page.
2. Select **Report a vulnerability** to create a private report.
3. Include the affected commit or version, impact, reproduction steps or proof of concept, and
   any known mitigation.

Remove credentials, personal data, customer content, and unrelated secrets from the report.
Use minimal synthetic data wherever possible.

Maintainers will review reports when available, may request clarification, and will coordinate
disclosure when a fix is ready. This volunteer project does not guarantee a response or repair
time. Please do not disclose the issue publicly before coordination is complete.

Ordinary defects and feature requests belong in the repository's public issue forms.
